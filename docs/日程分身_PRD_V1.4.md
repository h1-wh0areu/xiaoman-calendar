## 1. 产品概述

### 1.1 一句话定位

> **你的日程数字分身：日程表上每一条，它替你到场——你只管出现，它负责 ready。**

### 1.2 解决的核心问题

现代人不是缺一个日历（手机自带），而是**在日程上不断失手**：

- 日程散落在钉钉、Outlook、微信、纸质本上 → 没有一个地方看得见全貌
- 会前没准备 → 会议表现差
- 忘了自己承诺过什么 → 职场信用流失
- 家庭日程与工作日程撞车 → 两头都得罪
- 父母忘记吃药、子女打电话也劝不动 → 揪心又无力
- 孩子的课表、复习计划全靠吼 → 亲子内耗
- 证件到期浑然不觉，临到出国/开车才发现 → 误事又罚款
- 家人生日、复诊、家长会遗忘 → 留下遗憾；记得生日却想不出送什么 → 心意打折

### 1.3 核心洞察

1. **日程是AI最容易理解的结构化人生数据**（时间+人物+事项三元组）
2. **日程是分身"事前介入"的唯一合法入口**——没有日程的分身只能被动响应，有日程的分身可以未卜先知
3. **日程是唯一穿透所有行业、层级、年龄的人群公约数**
4. **同步是入口，不是功能**：用户散落在钉钉/Outlook 里的日程，谁帮TA聚合，谁就赢得 TA 的时间主权（V1.1 新增）

### 1.4 与竞品的本质差异

| 竞品 | 本质 | 我们的差异 |
|---|---|---|
| 苹果/华为日历 | 记账本（只记录） | 事前备/事中陪/事后追 |
| 飞书/钉钉日程 | 门牌（只同步） | 聚合钉钉+Outlook+微信，人格化分身+跨域仲裁 |
| 滴答清单/Todoist | 待办工具（只管清单） | 日程即场景，含家庭组群与银发守护 |
| ChatGPT类助手 | 聊天框（看不见你的时间） | 住进日程表，时机精准 |

## 2. 产品架构

### 2.1 总体架构：一个底座 × 三个参数

```
                    ┌─────────────────────────────┐
                    │        记忆底座（唯一）        │
                    │  语气/关系网/全部日程/优先级偏好  │
                    └──────────────┬──────────────┘
                                   │ 按人群调参
        ┌──────────────────────────┼──────────────────────────┐
   人格光谱              界面密度              场景权重
（语气/性格）          （信息量/字号）        （哪类日程优先）
        └──────────────────────────┼──────────────────────────┘
                                   │
   银发版 / 学生版 / 职场版 / 老板版 / 宝妈版 / 自由职业版
   = 同一引擎的不同面具，零重复开发
```

### 2.2 核心功能五原语

| 原语 | 说明 | 典型配方 |
|---|---|---|
| 记住 | 提取并归档关键信息 | 承诺项 / 人物卡 / 家庭日子 |
| 提醒 | 时机正确地出现 | 会前20分钟 / T-14天冲突预警 / 服药电话 |
| 备稿 | 事前把话和材料备好 | 会前小抄 / 祝福草稿 / 请假话术 |
| 代办 | 轻执行闭环（签发制） | 委托分身列席会议 / 代订蛋糕 |
| 复盘 | 事后提炼沉淀 | 参会回执 / 承诺闭环 / 复习掌握度曲线 |

### 2.3 分身三段式（每条日程的服务闭环）

```
事前·备 ──→ 事中·陪 ──→ 事后·追
会前小抄     实时纪要/       承诺追踪/
人物卡       承诺捕获        复盘沉淀
     ↑                        │
     └──── 记忆底座持续喂养 ──┘
```

### 2.4 三端形态与平台覆盖（V1.1 新增）

| 形态 | 平台 | 定位 | 核心差异体验 |
|---|---|---|---|
| 手机 App（主端） | iOS / Android | 全功能载体 | 推送/锁屏小组件/实况活动/语音交互/电话提醒接收 |
| 微信小程序（轻端） | 微信 | 获客+家庭协同 | 免下载、家庭邀请裂变、老人/学生低门槛接入、签发台轻操作 |
| PC 应用（生产力端） | macOS / Windows | 职场深度场景 | 会前小抄桌面弹层、全局快捷键唤起、会议纪要转写、多屏时间轴 |

**端间一致性原则**：
- **FR-0.1** 三端数据实时同步（WebSocket + 离线增量合并），任一端操作 5 秒内全端可见
- **FR-0.2** 小程序端覆盖核心闭环：查看日程、接收提醒、签发、家庭认领；复杂配置（人格光谱、同步源绑定）引导至 App 完成
- **FR-0.3** PC 端与系统日历（macOS Calendar / Windows 日历）双向互通，支持菜单栏/任务栏常驻今日视图
- **FR-0.4** 同一账号最多同时登录 5 台设备，异常登录短信二次验证

**跨端统一编译方案（V1.3 新增）**：
- **FR-0.5** 一套代码基座编译输出五端：移动双端（iOS/Android）与 PC 双端（macOS/Windows）采用统一跨平台框架（Flutter），微信小程序采用 Taro 同构输出；核心业务逻辑（日程引擎/提醒调度/同步合并/AI 编排）下沉为跨端共享层，五端复用率 ≥ 80%
- **FR-0.6** 功能对齐矩阵：新功能默认五端同版本发布；平台能力差异项（如 iOS 实况活动、Windows 任务栏驻留）以平台插件层实现，不得造成功能分叉
- **FR-0.7** 发布纪律：五端同火车发版，小程序审核期作为缓冲；热修复仅限 UI 层，逻辑层修复须全端回归
- **FR-0.8** UI 自适应：同一设计系统按端自适应（PC 宽幅时间线 / App 纵向流 / 小程序精简卡），银发模式五端均可一键切换

### 2.5 存储与同步架构：云端协同 × 本地多方案（P0 · V1.3 新增 · 隐私优先）

```
            ┌─────────────── 用户选择存储方案 ───────────────┐
   方案A 云端协同（默认）        方案B 端到端加密云        方案C 纯本地模式
   多设备实时同步/家庭协同       服务器只见密文            数据不出设备
   AI 全量能力                  AI 能力受限(端侧处理)     仅基础提醒, 无分身智能
   └───────────┬──────────────────────┬────────────────────┘
               │     敏感字段分级（无论哪个方案）             │
   L0 公开日程元数据 → 云端明文索引（时间/标题，用于同步调度）
   L1 日程详情/纪要 → 云端加密存储（密钥用户侧派生）
   L2 证件原件图像/录音 → 仅本地加密存储，云端仅存到期日元数据
   L3 企业域日历内容 → 不进入 AI 管道，仅时间占位
```

- **FR-2.5.1** **云端跨系统协同同步**：多端（App/小程序/PC）× 多人（家庭组群）× 多日历源（钉钉/Outlook/飞书等）实时协同，基于操作日志（CRDT 思想）合并冲突，离线编辑重连后自动收敛；协同变更 5 秒内全端可见
- **FR-2.5.2** 家庭协同编辑：共享日程的修改带操作者留痕；认领/确认动作实时广播组群
- **FR-2.5.3** **本地存储多方案**：注册时三方案明示选择，可随时切换（切换有数据迁移向导）：
  - 方案A 云端协同（默认）：全功能
  - 方案B 端到端加密云：同步照常但服务器不可读，AI 生成改由端侧小模型处理，能力降级明示
  - 方案C 纯本地模式：数据不出设备，仅保留本地提醒与基础日程，导出/销毁自助完成
- **FR-2.5.4** 隐私分级铁律：L2/L3 数据任何方案下均不上传云端明文；记忆底座中偏好类数据可单条查看、单条删除
- **FR-2.5.5** 数据主权：一键导出（标准 iCal + JSON 全量包）、一键销毁（云端+备份 30 天内物理删除并出具销毁回执）
- **FR-2.5.6** 备份策略：本地模式提供加密本地备份文件（用户自持密码，丢失不可找回——明示风险）；云端方案多副本容灾，RPO ≤ 5 分钟

**验收标准**：协同冲突自动收敛率 ≥ 99.9%；三方案切换迁移成功率 100%；销毁请求 30 天内完成率 100%

## 3. 功能需求（FRD）

### 3.1 账号与登录（V1.1 新增）

- **FR-1.1** **手机号为主登录 ID**：手机号+短信验证码为唯一主账号体系；微信号、Apple ID、邮箱仅作辅助绑定，不另立账号
- **FR-1.2** 微信内打开小程序时，支持微信手机号快速授权（一键取号）
- **FR-1.3** 换手机号支持自助换绑（原号验证 + 人脸/紧急联系人兜底），分身记忆与家庭关系随账号迁移
- **FR-1.4** 长辈模式：子女可为老人代注册（需老人本机短信确认一次），此后老人端免登录常驻
- **FR-1.5** 一人一号原则：家庭组群内每位成员独立账号，通过组群关联（见 §3.9）

### 3.2 多平台日程同步（V1.1 新增 · P0 地基功能）

- **FR-2.1** 支持以下同步源，OAuth / CalDAV / 开放 API 三种接入方式：
  | 同步源 | 方式 | 方向 |
  |---|---|---|
  | 钉钉日程 | 钉钉开放平台 API | 双向 |
  | 微软 Outlook / Exchange / M365 | Microsoft Graph API | 双向 |
  | 飞书日历 | 飞书开放平台 API | 双向 |
  | 企业微信日程 | 企业微信 API | 双向 |
  | Google 日历 | Google Calendar API | 双向 |
  | 系统日历（iOS/Android） | 系统权限读取 | 双向 |
  | 其他 CalDAV（QQ邮箱等） | CalDAV 协议 | 双向 |
- **FR-2.2** 同步策略：增量同步（Webhook 优先，轮询 15 分钟兜底）；首次全量同步 ≤ 2 分钟（5000 条以内）
- **FR-2.3** 冲突合并规则：同一事件多来源按「最后修改时间 + 来源优先级（用户可配）」合并，保留来源角标
- **FR-2.4** 写回可选：用户在分身内新建/修改日程，可写回指定日历（默认写回主日历）
- **FR-2.5** 企业合规提示：检测到 Exchange/企业微信等组织日历时，提示用户确认企业数据授权政策，企业域数据默认不进入 AI 处理管道（仅做时间占位展示）
- **FR-2.6** 断连治理：同步源授权过期前 3 天预警；断连超 7 天该来源日程置灰并引导重连

**验收标准**：主流源（钉钉/Outlook/飞书）同步成功率 ≥ 99%；增量延迟 P95 ≤ 60 秒

### 3.3 晨间值班报告（P0）

- **FR-3.1** 每日 7:30（可配置）推送当日时间轴：全部日程（含各同步源聚合）+ 每段的分身准备状态
- **FR-3.2** 冲突日程以橙色置顶突出，标注"X 个雷"
- **FR-3.3** 报告结尾固定出现安全感承诺语（"其余的，我都备好了"）
- **FR-3.4** 晨间报告全量免费：每日 1 条 + 完整方案，不设条数限制（V1.4 起）
- **FR-3.5** 三端触达：App 推送 + 小程序订阅消息 + PC 桌面通知，用户可设定主触达端

**验收标准**：报告打开率 ≥ 60%；平均阅读时长 ≥ 15 秒

### 3.4 关键日程时间线视图（P0 · V1.3 新增）

- **FR-4.1** 多尺度时间线：支持未来 **1 个月 / 3 个月 / 6 个月 / 1 年** 四档横向时间线视图，双指缩放平滑切换粒度；默认首页为「1 个月」
- **FR-4.2** 关键日程聚合：按域着色分区——工作（蓝）、家庭（橙）、证件/缴费（红）、生日/纪念日（粉）、学习（绿）、健康（紫）；关键日程（用户标星或 AI 判定高重要度）在时间线上放大置顶
- **FR-4.3** 密度热力提示：时间线下方渲染日程密度热力条，高密度周自动提示"本周过载，建议移出 X 项可委托日程"
- **FR-4.4** 里程碑视图：1 年档自动收敛为里程碑模式（只显示关键日程与重要日子），适合年度规划与春节"一年展望"分享卡片
- **FR-4.5** 分身在场标记：时间线上每条日程显示分身准备状态图标（已备稿/待签发/已安排提醒），一眼看见"分身为我准备好了多少"
- **FR-4.6** 三端一致：PC 端宽幅时间线为主视图；App 端纵向滚动时间轴；小程序端提供 1 个月精简视图
- **FR-4.7** 空窗洞察：识别连续空档并给出建议（"下月第二周完全没有家庭日程，要安排一次团聚吗"），低频低打扰（每月 ≤ 1 次）

**验收标准**：时间线视图周使用率 ≥ 50%；视图切换响应 ≤ 300ms；1 年档渲染 500 条日程不卡顿

### 3.5 日程冲突提醒与决策（P0 · 独门武器，V1.1 升级）

- **FR-5.1** 跨日历域冲突检测：工作日历（钉钉/Outlook）× 家庭日历 × 个人日历 × 课表，提前 14 天预警
- **FR-5.2** 三步闭环：**提醒（T-14/T-3/T-0 三档）→ 双方案（倾向A/倾向B）→ 一键执行**（自动发请假话术/改约邀请/通知家人）
- **FR-5.3** 每方案含完整执行件（话术草稿/替代人建议/补偿方案），执行件经签发台签发后发出
- **FR-5.4** 显示用户历史优先级作为建议依据（可调整），并记录每次决策反哺记忆底座
- **FR-5.5** **产品宪法：建议权在AI，决定权在人——所有仲裁仅提供建议，最终按钮永远由用户点击**

## 5. 非功能需求

### 5.1 合规与伦理（产品宪法，不可妥协）

1. **建议权在AI，决定权在人**：所有对外动作签发制（L2以下强制）
2. **数据授权**：个人/家庭/企业数据物理隔离；敏感个人信息单独同意；可导出可销毁
3. **老人知情**：代际/家庭功能必须让长辈本人知道并同意（短信确认即留痕）
4. **AI标识**：分身列席会议、对外发送内容默认带AI标识（可设置）
5. **真人语音红线**：服药电话仅播放子女本人录音，禁止声音克隆合成新语音
6. **企业数据合规**：组织日历（Exchange/企业微信）数据遵循企业授权范围，企业域内容不进入 AI 训练与处理管道；受管设备剪贴板识别默认关闭
7. **隐私分级存储**：证件原件/录音仅本地加密；敏感字段按 L0–L3 分级（见 §2.5）；剪贴板仅本地解析、用完即弃
8. **生成式AI备案**：上线前完成算法备案与安全评估；电话外呼线路完成通信管理局相关资质备案
9. **仲裁红线**：未确认日子/低置信度冲突绝不主动提醒

### 5.2 性能

- 除夕峰值按预估 10 倍压测；生成排队+异步降级
- 小抄生成 P95 ≤ 3 秒；降级预案：预置模板兜底，**宁可平庸不可宕机**
- 日程同步增量延迟 P95 ≤ 60 秒；服药电话外呼触发延迟 P99 ≤ 30 秒（生命攸关级 SLA）
- 三端同步一致性：任一端操作 5 秒内全端可见；协同冲突自动收敛率 ≥ 99.9%
- 时间线视图切换响应 ≤ 300ms；1 年档 500 条日程流畅渲染
- 剪贴板识别端侧耗时 ≤ 500ms，卡片弹出延迟 ≤ 1 秒

### 5.3 通知纪律

- 每周主动触达 ≤ 2 次（通知预算制），其余靠主动打开拉动
- **例外条款**：服药守护、冲突 T-0、承诺逾期三类安全级提醒不计入预算

## 6. 商业模式（V1.4 重构：核心功能全免费）

### 6.1 基本原则

**App 全部功能永久免费**——日程同步、会前小抄、冲突仲裁、代出席、证件守护、服药电话外呼、生日方案引擎、家庭组群、时间线视图等全部功能不做任何功能阉割、不设用量上限、不搞订阅墙。理由：

1. 分身的价值依赖数据密度与使用时长，任何付费墙都会压扁记忆底座的喂养速度
2. 春节档爆发策略要求零门槛裂变，免费是传播杠杆
3. 日程入口的终身价值远高于订阅费：谁掌握一个人的时间，谁就站在所有消费的上游

### 6.2 未来变现方向（衍生场景与增值服务，不影响核心免费承诺）

| 方向 | 形态 | 触发点（情感峰值） | 阶段 |
|---|---|---|---|
| 场景电商佣金 | 生日方案卡内的礼物/蛋糕/鲜花/餐厅预订，按成交分佣 | 生日方案被采纳时 | 近期（V1.x 内灰度） |
| 政务/证件代办导流 | 换证预约、年检代办、签证服务导流分佣 | 证件预警处置时 | 近期 |
| 企业团队版 | 团队承诺看板/共享客户日历/企业域数据隔离，按席位收费（B 端，不影响个人免费） | 老板版自然溢出到团队 | 中期 |
| 增值服务包 | 深度人格定制（专属声音形象/高阶幕僚模型）、数据保险柜扩容、专属客服 | 信任等级 L3+ 用户 | 中期 |
| 适老/教育硬件 | 服药提醒音箱、老人一键呼叫器、学生专注计时器 | 家庭守护场景 | 远期 |
| 保险/健康服务导流 | 复诊提醒→体检套餐、车辆年检→车险比价，合规导流 | 对应日程场景 | 远期 |

### 6.3 商业化纪律（红线）

1. **核心功能永不禁售**：已免费的功能永不收回为付费项
2. **导流必须长在场景里**：只在方案卡/预警处置等自然触点出现，不做弹窗广告、不卖信息流
3. **推荐可信**：礼物/服务推荐标注"合作/佣金"标识，AI 推荐逻辑与佣金脱敏（先按偏好排序，再看是否有合作供给）
4. **数据永不售卖**：任何变现方式不涉及用户数据出售或画像外供

## 8. 指标体系

**北极星：周分身在场次数** = 小抄被读 + 回执被看 + 承诺被闭环 + 冲突被预警签收 + 服药提醒被确认 + 证件预警被处置 + 生日方案被采纳

健康度预警线：
- 方案采用率 < 30% → 方案引擎重做
- 人均日历条目 < 15 → 建档漏斗有问题（同步源接入率重点排查）
- 签发前修改率 > 50% → 语气模型不过关，暂停L2开放
- 同步源人均绑定 < 1.5 个 → 同步引导流程重做（V1.1 新增）
- 服药确认率 < 85% → 触达链路复盘（V1.1 新增）
- 生日方案采纳率 < 30% 或礼物"记错偏好"纠错率 > 15% → 记忆底座偏好模型重做（V1.2 新增）
- 证件预警后 7 日处置率 < 40% → 预警节奏与指引卡内容重做（V1.2 新增）
- 关键日程错过率 ≥ 2% → 提醒引擎提前量规则重做（V1.3 新增）
- 时间线周使用率 < 40% → 视图信息密度与入口位置重做（V1.3 新增）
- 剪贴板一键建档转化率 < 25% → 识别准确率与弹卡时机重做（V1.3 新增）
